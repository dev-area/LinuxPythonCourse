# 5 · Command Reference (utilities) — Exercises

> Answers: [answers/05-command-reference.md](../answers/05-command-reference.md)

**1.** Use `cut` to extract the first (colon-delimited) field of `/etc/passwd`.

**2.** Extract characters 1–8 of every line of a fixed-width file.

**3.** Sort a file of numbers in descending numeric order.

**4.** Remove duplicate lines from `names.txt` (output sorted, each once).

**5.** Sort `/etc/passwd` by numeric UID (the 3rd colon-separated field).

**6.** Show the 5 most frequent IP addresses (first field) in `access.log`.

**7.** Count how many UNIQUE IPs appear in `access.log`.

**8.** Show the lines that appear only in `a.txt` and not in `b.txt` (both sorted).

**9.** Count the words, lines and characters of `essay.txt`.

**10.** Use `bc` to compute `22 / 7` to 4 decimal places.

**11.** Sum a column of numbers using `paste` and `bc`.

**12.** Produce a unified-format patch between `old.c` and `new.c` and save it to `change.patch`.

**13.** Using `df` and `du`, find which sub-directory of `/home` uses the most space.

**14.** Give an example where `file` reports a type the extension does not.

**15.** Merge `names.txt` and `ages.txt` into two comma-separated columns.

**16.** Join `employees.txt` and `salaries.txt` on their common first field.

**17.** Wrap a long text file to 60 columns without breaking words.

**18.** Show the raw bytes of a small file in hex.

**19.** Split `big.log` into pieces of 1000 lines each, named `part_`.

**20.** Schedule a one-off job to run `backup.sh` in 10 minutes.
