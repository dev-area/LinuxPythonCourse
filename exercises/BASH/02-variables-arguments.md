# דף 2 – משתנים, ארגומנטים ו‑`set --`

➡️ חזרה ל[דף 1](01-intro.md)

## משתנים

**משתנה** הוא שם ששומר ערך. ב‑BASH מגדירים משתנה **בלי רווחים** סביב ה‑`=`:

```bash
name="דנה"
age=25
```

> חשוב: `name = "דנה"` (עם רווחים) **לא יעבוד**! חייב להיות צמוד: `name="דנה"`.

כדי **לקרוא** את ערך המשתנה, מוסיפים `$` לפני השם:

```bash
echo "$name"
echo "הגיל הוא $age"
```

דוגמה להעתקה והרצה (קובץ `vars.sh`):

```bash
#!/bin/bash

name="דנה"
age=25

echo "שם: $name"
echo "גיל: $age"

# מומלץ לעטוף בסוגריים מסולסלים כשמצמידים טקסט
echo "בעוד שנה היא תהיה בת ${age} ועוד קצת"
```

### גרשיים – ההבדל החשוב

- **גרשיים כפולים** `"..."` – המשתנים **מוחלפים** בערכם.
- **גרש בודד** `'...'` – הטקסט נשאר **בדיוק כמו שהוא**, בלי החלפה.

```bash
#!/bin/bash
word="BASH"
echo "אני לומד $word"   # ידפיס: אני לומד BASH
echo 'אני לומד $word'   # ידפיס: אני לומד $word
```

### קליטת פלט של פקודה למשתנה

```bash
#!/bin/bash
today=$(date +%Y-%m-%d)
files_count=$(ls | wc -l)

echo "התאריך היום: $today"
echo "מספר הקבצים בתיקייה: $files_count"
```

- `$(command)` מריץ את הפקודה ושם את הפלט שלה במשתנה.

## ארגומנטים לסקריפט

ארגומנטים הם ערכים שמעבירים לסקריפט **בזמן ההרצה**:

```bash
./myscript.sh apple banana cherry
```

בתוך הסקריפט ניגשים אליהם כך:

| משתנה | משמעות |
|-------|--------|
| `$0` | שם הסקריפט עצמו |
| `$1`, `$2`, `$3` ... | הארגומנט הראשון, השני, השלישי... |
| `$#` | מספר הארגומנטים |
| `$@` | כל הארגומנטים (כרשימה) |
| `$*` | כל הארגומנטים (כמחרוזת אחת) |

דוגמה (קובץ `args.sh`):

```bash
#!/bin/bash

echo "שם הסקריפט: $0"
echo "ארגומנט ראשון: $1"
echo "ארגומנט שני: $2"
echo "מספר הארגומנטים: $#"
echo "כל הארגומנטים: $@"
```

הרצה:

```bash
chmod +x args.sh
./args.sh apple banana
```

פלט צפוי:

```
שם הסקריפט: ./args.sh
ארגומנט ראשון: apple
ארגומנט שני: banana
מספר הארגומנטים: 2
כל הארגומנטים: apple banana
```

### מעבר על כל הארגומנטים

```bash
#!/bin/bash
echo "קיבלתי $# פריטים:"
for item in "$@"; do
    echo " - $item"
done
```

## הפקודה `set --`

הפקודה `set --` מאפשרת **לקבוע מחדש** את הארגומנטים (`$1`, `$2`, ...) מתוך הסקריפט,
גם אם הסקריפט לא קיבל אותם מבחוץ. זה שימושי מאוד כשרוצים לפרק מחרוזת לחלקים.

דוגמה בסיסית (קובץ `set_demo.sh`):

```bash
#!/bin/bash

# קובעים ידנית את הארגומנטים
set -- red green blue

echo "עכשיו \$1 הוא: $1"
echo "עכשיו \$2 הוא: $2"
echo "מספר הפריטים: $#"
```

פלט:

```
עכשיו $1 הוא: red
עכשיו $2 הוא: green
מספר הפריטים: 3
```

### שימוש אמיתי – פירוק מחרוזת

נניח שיש לנו תאריך כמחרוזת ואנחנו רוצים לפרק אותו לחלקים:

```bash
#!/bin/bash

date_str="2026-11-21"

# מחליפים את ה- "-" ברווח, ומפצלים את המחרוזת לארגומנטים
IFS='-' set -- $date_str

echo "שנה:  $1"
echo "חודש: $2"
echo "יום:  $3"
```

> `IFS` (Internal Field Separator) קובע לפי איזה תו לפצל. כאן בחרנו ב‑`-`.

> שימו לב ל‑`--`: הוא מסמן ש"כאן נגמרות האפשרויות ומתחילים הערכים",
> וחשוב במיוחד כשהערך הראשון עלול להתחיל ב‑`-`.

## תרגיל

כתבו סקריפט `fullname.sh` ש:

1. מקבל שם מלא כארגומנט אחד במרכאות, לדוגמה: `./fullname.sh "ישראל ישראלי"`.
2. משתמש ב‑`set --` כדי לפצל את השם הפרטי ושם המשפחה.
3. מדפיס:
   - שם פרטי
   - שם משפחה
   - מספר המילים בשם

דוגמה להרצה ולפלט:

```
./fullname.sh "ישראל ישראלי"
שם פרטי: ישראל
שם משפחה: ישראלי
מספר מילים: 2
```

נסו לבד! 👇

## פתרון

```bash
#!/bin/bash

# הארגומנט המלא מגיע ב-$1 (כי הוא עטוף במרכאות)
full_name="$1"

# מפצלים לפי רווח: set -- מפזר את המחרוזת למילים נפרדות
set -- $full_name

echo "שם פרטי: $1"
echo "שם משפחה: $2"
echo "מספר מילים: $#"
```

הרצה:

```bash
chmod +x fullname.sh
./fullname.sh "ישראל ישראלי"
```

**מה למדנו:** `set --` הופך מחרוזת אחת לרשימת ארגומנטים ניתנת לגישה דרך `$1`, `$2`, `$#`.
