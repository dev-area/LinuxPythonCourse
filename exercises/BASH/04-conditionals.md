# דף 4 – תנאים (Conditionals)

➡️ חזרה ל[דף 3](03-signals.md)

תנאים מאפשרים לסקריפט "לקבל החלטות" – להריץ קוד מסוים רק אם משהו נכון.

## מבנה בסיסי – `if`

```bash
if [ תנאי ]; then
    # קוד שרץ אם התנאי נכון
fi
```

> שימו לב לרווחים! חייבים רווח אחרי `[` ולפני `]`. זה טעות נפוצה מאוד.

דוגמה (קובץ `age_check.sh`):

```bash
#!/bin/bash
age=20

if [ "$age" -ge 18 ]; then
    echo "בגיר/ה"
fi
```

### `if ... else`

```bash
#!/bin/bash
age=15

if [ "$age" -ge 18 ]; then
    echo "בגיר/ה"
else
    echo "קטין/ה"
fi
```

### `if ... elif ... else`

```bash
#!/bin/bash
grade=75

if [ "$grade" -ge 90 ]; then
    echo "מצוין"
elif [ "$grade" -ge 70 ]; then
    echo "טוב"
elif [ "$grade" -ge 60 ]; then
    echo "עובר"
else
    echo "נכשל"
fi
```

## השוואת מספרים

| אופרטור | משמעות | דוגמה |
|---------|--------|-------|
| `-eq` | שווה (equal) | `[ "$a" -eq "$b" ]` |
| `-ne` | לא שווה | `[ "$a" -ne "$b" ]` |
| `-gt` | גדול מ‑ (greater than) | `[ "$a" -gt "$b" ]` |
| `-ge` | גדול או שווה | `[ "$a" -ge "$b" ]` |
| `-lt` | קטן מ‑ (less than) | `[ "$a" -lt "$b" ]` |
| `-le` | קטן או שווה | `[ "$a" -le "$b" ]` |

## השוואת מחרוזות

| אופרטור | משמעות |
|---------|--------|
| `=` | שתי מחרוזות זהות |
| `!=` | מחרוזות שונות |
| `-z` | המחרוזת ריקה (zero length) |
| `-n` | המחרוזת לא ריקה |

```bash
#!/bin/bash
name="דנה"

if [ "$name" = "דנה" ]; then
    echo "שלום דנה!"
fi

if [ -z "$password" ]; then
    echo "לא הוזנה סיסמה"
fi
```

## בדיקות על קבצים

| אופרטור | נכון אם... |
|---------|-----------|
| `-e` | הקובץ קיים (exists) |
| `-f` | זהו קובץ רגיל |
| `-d` | זו תיקייה (directory) |
| `-r` | יש הרשאת קריאה |
| `-w` | יש הרשאת כתיבה |
| `-x` | יש הרשאת הרצה |
| `-s` | הקובץ לא ריק (size > 0) |

```bash
#!/bin/bash
file="data.txt"

if [ -f "$file" ]; then
    echo "הקובץ קיים"
else
    echo "הקובץ לא נמצא"
fi
```

## תנאים מורכבים – AND, OR, NOT

| מפעיל | משמעות |
|-------|--------|
| `&&` | וגם (AND) |
| `\|\|` | או (OR) |
| `!` | שלילה (NOT) |

```bash
#!/bin/bash
age=25
has_license="yes"

if [ "$age" -ge 18 ] && [ "$has_license" = "yes" ]; then
    echo "מותר לנהוג"
fi

if [ "$age" -lt 16 ] || [ "$age" -gt 120 ]; then
    echo "גיל לא סביר לנהיגה"
fi
```

> אפשר גם להשתמש בסוגריים כפולים `[[ ... ]]`, שהם גמישים יותר ב‑BASH
> ומאפשרים לכתוב `&&` ו‑`||` בתוך אותם סוגריים:
> ```bash
> if [[ "$age" -ge 18 && "$has_license" = "yes" ]]; then
>     echo "מותר לנהוג"
> fi
> ```

## מבנה `case` – בחירה מרובת אפשרויות

כש‑`elif` רבים הופכים את הקוד למסורבל, `case` נקי יותר:

```bash
#!/bin/bash
read -p "בחרו אפשרות (a/b/c): " choice

case "$choice" in
    a)
        echo "בחרת A"
        ;;
    b)
        echo "בחרת B"
        ;;
    c)
        echo "בחרת C"
        ;;
    *)
        echo "בחירה לא חוקית"
        ;;
esac
```

- כל אפשרות מסתיימת ב‑`;;`.
- `*)` הוא "כל השאר" (ברירת מחדל).
- `read -p` מקבל קלט מהמשתמש.

## תרגיל

כתבו סקריפט `filecheck.sh` שמקבל שם קובץ כארגומנט (`$1`) ו:

1. אם לא הועבר ארגומנט כלל – ידפיס "אנא ספקו שם קובץ" ויצא.
2. אם הקובץ לא קיים – ידפיס "הקובץ לא קיים".
3. אם הקובץ קיים אך ריק – ידפיס "הקובץ ריק".
4. אם הקובץ קיים ולא ריק – ידפיס "הקובץ קיים ומכיל נתונים".

נסו לבד! 👇

## פתרון

```bash
#!/bin/bash

filename="$1"

# 1. בדיקה שהועבר ארגומנט (מחרוזת ריקה?)
if [ -z "$filename" ]; then
    echo "אנא ספקו שם קובץ"
    exit 1
fi

# 2-4. בדיקות על הקובץ
if [ ! -e "$filename" ]; then
    echo "הקובץ לא קיים"
elif [ ! -s "$filename" ]; then
    echo "הקובץ ריק"
else
    echo "הקובץ קיים ומכיל נתונים"
fi
```

הרצה ובדיקה:

```bash
chmod +x filecheck.sh
./filecheck.sh                 # בלי ארגומנט
./filecheck.sh nofile.txt      # קובץ שלא קיים
touch empty.txt
./filecheck.sh empty.txt       # קובץ ריק
echo "hello" > data.txt
./filecheck.sh data.txt        # קובץ עם תוכן
```

**מה למדנו:** שילוב של בדיקת מחרוזת ריקה (`-z`), קיום קובץ (`-e`), גודל (`-s`) ושלילה (`!`).
