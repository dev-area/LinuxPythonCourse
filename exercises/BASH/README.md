# מדריך BASH – צעד אחר צעד

ברוכים הבאים למדריך ללימוד תכנות ב‑BASH. המדריך בנוי כסדרת דפים, כל דף מסביר כמה נושאים,
כולל **דוגמאות להעתקה והרצה** ו**תרגיל עם פתרון** בסוף.

## איך לומדים מהמדריך

1. קראו את ההסבר בכל דף.
2. העתיקו כל דוגמה לקובץ או לטרמינל והריצו אותה בעצמכם – אל תסתפקו בקריאה.
3. פתרו את התרגיל שבסוף הדף **לפני** שאתם מציצים בפתרון.

## דרישות מקדימות

- מערכת Linux / macOS, או ב‑Windows: WSL או Git Bash.
- עורך טקסט כלשהו (VS Code, nano, vim).
- טרמינל פתוח.
